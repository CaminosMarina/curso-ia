# Cómo empezar

Para estudiar este curso solo necesitás este sitio. No hace falta pagar nada ni crear cuentas para arrancar.

## 1. Mirá la ruta

En [Ruta](../ruta/index.md) está el mapa del curso: cinco etapas y dieciocho módulos, con lo que conviene hacer antes de cada uno. Cada módulo tiene una portada con su objetivo, las herramientas que vas a usar y sus lecciones.

## 2. Hacé la primera lección

Empezá por [Cómo funciona este curso](../m00-orientacion/l0-1-1-mapa-del-curso.md). Explica cómo están armadas las lecciones, cómo se marca el avance y cómo elegir tu recorrido.

## 3. Estudiá cada lección en este orden

1. **Teoría:** leela completa. Es breve y va directo a los conceptos.
2. **Práctica:** seguí los pasos. Cada paso dice qué tenés que ver si salió bien.
3. **Autoevaluación:** respondé las preguntas. La página te corrige y te explica cada respuesta.
4. **Marcá la lección:** al final de cada lección hay un botón para marcarla como *En curso* o *Completada*.

## 4. Seguí tu avance

En [Mi progreso](../progreso.md) ves cuánto llevás por módulo y por etapa, y desde dónde retomar.

> [!NOTE]
> **Dónde se guarda tu progreso**
>
> Se guarda en tu navegador, en esta computadora. No se envía a ningún servidor ni lo ve nadie más. Si cambiás de computadora o de navegador, o si borrás los datos del sitio, empezás de cero. Para no perderlo, desde *Mi progreso* podés descargar una copia y cargarla en otro lado.

## Si querés más método

Si te gusta llevar registro propio, con apuntes, horas y repasos, la guía [Cómo estudiar](metodo.md) propone un cuaderno de estudio. Es opcional.

Si querés estudiar con un asistente de IA (Claude, ChatGPT u otro) como tutor, seguí [Estudiar con un tutor de IA](tutor.md). Tampoco es necesario: cada lección se puede hacer sola.

## Costos

El Módulo 0 se hace con herramientas y cuentas gratuitas. Cuando una lección necesita un plan pago, una API paga o infraestructura adicional, lo indica al principio, en "Antes de empezar", y ofrece una alternativa gratuita cuando existe.

## Mantenerte al día

El sitio siempre muestra la última versión. Los cambios importantes se anotan en el [registro de cambios](https://github.com/CaminosMarina/curso-ia/blob/main/CHANGELOG.md). Si el programa cambia de una forma que afecte tu avance, [Versiones y cambios](../sobre/versiones.md) explica qué hacer.
