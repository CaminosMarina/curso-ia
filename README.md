# Formación Integral en Inteligencia Artificial

**De fundamentos a agentes y automatización avanzada.** Curso abierto, progresivo y autodidacta para aprender a usar, configurar, integrar y desarrollar soluciones con IA: modelos de lenguaje, prompt y context engineering, asistentes, agentes de programación, RAG, agentes, MCP, skills y plugins, n8n, sistemas multiagente y operación en producción.

> **Estado: en desarrollo, no publicado.** El programa completo está disponible, pero el material de las lecciones se escribe de forma progresiva. Ver [Estado de publicación](#estado-de-publicación).

## Objetivos

Al terminar el curso vas a poder:

- Usar con criterio asistentes de IA, agentes de programación y automatizaciones, sabiendo qué herramienta conviene en cada caso y por qué.
- Explicar cómo funciona un modelo de lenguaje y usar ese modelo mental para diagnosticar comportamientos.
- Construir tus propias soluciones: integraciones por API, RAG evaluado, agentes desde cero y con frameworks, servidores MCP, skills, plugins y workflows de n8n.
- Llevarlas a producción con seguridad, evaluación, observabilidad y control de costos.

El perfil de egreso completo está en la sección 11 de [`PROGRAMA.md`](PROGRAMA.md).

## ¿Para quién es?

Para personas con **experiencia en programación** (idealmente backend: API REST, bases de datos, Python o Java) que **no tienen conocimientos previos de IA**. No se da por conocido ningún término específico de IA.

El curso está escrito en español rioplatense (voseo).

## Dos formas de estudiar

| Modalidad | Qué necesitás | Cómo empezar |
|---|---|---|
| **Autónoma** | El material del repositorio y un editor de texto | [`COMO-EMPEZAR.md`](COMO-EMPEZAR.md) |
